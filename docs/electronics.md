# Electronics v1 — schematic decisions (2026-11-22)

Schematics: `hardware/{driver,spine,tail}/*.kicad_sch` (+ PDF), generated by
`hardware/gen_*.py`. ERC clean. LCSC stock check done 2026-11-23 (stock
figures from search snapshots, recheck at order time).

## Changes vs. the plan

1. **DW01A + FS8205A dropped.** In the LED return path the FS8205A sits between
   the sense resistor and BODY, so its ~45 mΩ (temperature dependent) adds to the
   sensed voltage → current error of the same size as the 125 mV turbo setpoint.
   Its overcurrent trip (~3 A) is also too close to turbo. Overdischarge backup is
   now the ATtiny **BOD at 2.6 V** (fuse, sampled mode in sleep) + firmware LVP;
   all other loads (op-amp, sensors, NTC divider) are powered from GPIOs, so
   after LVP the only drain is the sleeping MCU (<1 µA). Saves ~0.11 V in turbo.
2. **Two current ranges** (open item "Low-mode current method" → decided):
   - Channel A, High/Turbo: Q1 DMN3008SFG + 0.05 Ω, reference DAC/7.9
     (47k/6.8k). DAC VREF 1.1 V → 0–2.8 A, 10.8 mA/step.
   - Channel B, Low: Q5 AO3400A + 4.7 Ω, reference = DAC directly. VREF 0.55 V
     → 0–117 mA, 0.46 mA/step. Op-amp offset (≤1.6 mV) = ≤0.34 mA here instead
     of ≤32 mA on the 0.05 Ω range.
   - One DAC feeds both; the unused channel is switched off by its KILL pin
     (GPIO high → 10k into the op-amp − input → output low). Both KILL pins hi-Z
     → both channels regulate (not used).
   - Op-amp TLV9002 (dual, RRIO), loop: 1k gate R, 100k gate pull-down,
     10k/10n integrator — tune on the bench.
3. **Q3 (charger disconnect) dropped.** Clicky ON while plugged in only puts the
   TP4057 into trickle (BAT shorted via BODY→CELL−); verify on the bench.

## Spine

U1 TMAG5273**A1** (C3716049, 0x35, rear/level ring), U2 TMAG5273**C1**
(C32969674, 0x78 per datasheet table 6-2, front/mode ring; LCSC stock thin/varies), 4.7k pull-ups to SENS_PWR (no drain when off), NTC
pads. INT unused.

## Tail

TE 2495702-1 USB-C (footprint to draw), 5.1k CC pull-downs, TP4057-42-SOT26-R
(C12044; I = 1000 V / R_PROG → 2.7k = 370 mA; 2.5k = 400 mA), 10 µF in/out, clicky between CELL−
and BODY (switch taken from the KDLITKER 16 mm module, footprint after
measuring), optional charge LEDs (DNP).

## Firmware consequences

- Fuses: BOD 2.6 V, sampled in sleep, enabled in active.
- Power-up order: OPA_PWR on → DAC → release KILL of the wanted channel.
- Mode change between ranges: set KILL on both, change VREF/DAC, release.
- Sensors: power SENS_PWR, wait ~1 ms, configure both (A1 0x35, C1 0x78).
